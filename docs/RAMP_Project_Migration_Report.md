## PROJECT 1 — MEMOIVA Circle

### What This Project Is

A facilitated 8-week language and cognitive health program for adults 50+. Conducted live via Zoom or in-person. Small cohorts of 5–8 participants. Spanish as the target language (Track A) or English as the target language for Spanish-dominant older adults (Track B — launching after Cohort 1 data exists). Haitian Creole and other languages to follow based on community demand.

The scientific foundation: bilingual cognitive reserve. A 2024 Concordia University study confirmed that learning a second language produces measurable hippocampal neuroplasticity — even later in life. MEMOIVA Circle is the only facilitated program in America built specifically around this finding.
